Sobre Mí

Trayectoria, enfoque y metas profesionales

Soy Edwin Emerson López Hernández, estudiante de Ingeniería en Sistemas y Redes Informáticas en la Universidad Gerardo Barrios (2022 - 2026). Me especializo en el desarrollo de software empresarial combinando arquitecturas robustas Backend (NestJS, TypeScript, PHP, C#), interfaces interactivas Frontend (React, Vite, Tailwind, JS) y flujos avanzados de Inteligencia Artificial Agéntica (Google Antigravity, Antigravity CLI y Open Code).

Cuento con experiencia en el diseño de plataformas modulares y escalables como sistemas ERP y E-Commerce con PostgreSQL, TypeORM y Facturación Electrónica (DTE). Además, domino el ecosistema de IA Agéntica (creación de skills, reglas contextuales, Model Context Protocol y automatizaciones con Antigravity CLI), respaldado por una sólida base de conectividad con certificaciones Cisco CCNA. Busco integrarme a una empresa mediante una pasantía técnica donde pueda aportar valor real desde el primer día.

Enterprise Digital Transform
Desarrollador Full Stack
Enterprise Digital Transform es una solución empresarial de alta escala compuesta por un ERP administrativo y una tienda E-Commerce con arquitectura desacoplada. Diseñada para gestionar el ciclo comercial completo de empresas modernas.
Arquitectura e Implementación Técnica: Desarrollado con NestJS v11 en el backend bajo arquitectura modular y TypeScript, base de datos PostgreSQL 18 con TypeORM y migraciones estructuradas, frontend moderno en React 19 + Vite 7 y Tailwind CSS, autenticación stateless con JWT (Access & Refresh Tokens), control de acceso por roles (RBAC), documentación Swagger y módulo de Facturación Electrónica (DTE).
Módulos y Capacidades del Sistema:
NestJS 11 React 19 & Vite 7 PostgreSQL 18 & TypeORM Facturación Electrónica (DTE) JWT & RBAC (Roles) Inventario, Compras & Ventas Tailwind CSS

Shulton Parking
Project Manager & Desarrollador
Shulton Parking es una solución web desarrollada para resolver la problemática de tráfico y optimizar la búsqueda de estacionamiento en zonas de alta congestión del distrito de Usulután. Permite a los conductores ubicar estacionamientos disponibles en tiempo real con datos de localización, horarios y tarifas.
Retos e Implementación Técnica: Desarrollado en PHP nativo siguiendo arquitectura modular del lado del servidor, base de datos relacional MySQL para gestionar disponibilidad y tarifas, e integración interactiva de la API de Google Maps con JavaScript para geolocalización precisa.
PHP MySQL JavaScript Google Maps API Bootstrap 5
